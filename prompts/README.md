# Cara menjalankan prompt

Prompt `.md` di direktori ini BUKAN slash commands. **Jangan** ketik `/prompts/02_TERRAIN.md`.

Di Claude Code CLI (root proyek):

```text
Read prompts/00_BASELINE_AND_DOC_SYNC.md and follow its instructions. Read current files before editing. Do not push or commit.
```

Lanjut urutan: `00` → `01` → `02` → `03` → `03A` → `03B` → `04` → `05`, tetapi **berhenti pada gate** yang bergantung pada kontrak data tim. Model, effort, skill, dan detail acceptance ada di `docs/MODEL_SKILL_PLAYBOOK.md`.
